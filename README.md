# Chess-Coach
A virtual chess coach for beginning learners

The idea is just to show players what moves are possible. No advice is provided regarding which of them might be best.

A sample starting position showing what the white king pawn can do on its next move looks like:

[Starting position, possible moves for white king pawn](images/chess01.png)

During the first few moves, any position that has a recognized name can be commented on:

[White queen starts a known opening line](images/chess02.png)

If a position has no recognized name or is beyond the first few moves, a tactic can be commented on:

[White queen checks black king and forks king and rook](images/chess03.png)

By default the program provides both players with all available help options. Individual options may be turned off for either player, the idea being to voluntarily 'handicap' the player who does so.

In this version the 'RECORD' button does nothing. In future versions it is meant to connect to a database of games and/or puzzles.
